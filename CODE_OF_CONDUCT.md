# Code of Conduct

This project adopts the **Contributor Covenant, version 2.1**, as its code of conduct. The full
text is at <https://www.contributor-covenant.org/version/2/1/code_of_conduct/> and applies to
every project space: issues, pull requests, discussions and any other channel the project uses.

In short: be respectful, assume good faith, criticise code and ideas rather than people, and no
harassment of any kind.
