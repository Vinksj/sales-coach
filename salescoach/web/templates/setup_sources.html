Before you switch this on
A cloud automation (Zapier, Make) can only reach the coach through a tunnel you run. Set the tunnel up so that it forwards only the path /import/webhook, and so that it does not rewrite the Host header. A tunnel that forwards everything, or that rewrites the Host header to localhost, puts your calls, deals and the Send button on the internet. The coach refuses every other request that arrives through a tunnel or proxy, but only the tunnel can keep them from arriving.
